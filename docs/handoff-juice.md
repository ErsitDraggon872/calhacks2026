# Handoff: add juice without touching the demo

This is for a Claude Code (or other) session on Wesley's PC. The project uses Unity 6000.3.18f1, and the Editor is
usually open (often in Play mode for playtesting), so drive it with the `unity` CLI (`unity command ...`) and ask
before stopping Play mode. Work on `main`, which is current as of `eb4a1c3`. Read [`README.md`](../README.md) first for
the demo route.

## Goal
Make BUILD, solving a puzzle and winning *feel* good: sound, small pops and particles. The demo's story is "your lines
decide its shape; AI decides what it is", so every effect must make that moment louder, never compete with it.

## Hard rules (the demo depends on these)
- **Visual only.** Never scale, move or rotate a GameObject that owns a collider. Silhouette colliders
  (`Inventions/SilhouetteBoxes.cs`) are the pitch: "solid only where there's ink". Animate a child sprite or a
  separate effect object.
- **No `Time.timeScale` changes, no hitstop.** `UI/InventionCard.cs` pauses the game with `timeScale = 0` until LET'S
  PLAY, and `UI/SpeechBubble.cs` and the verify scripts rely on that. Effects that play during the card must use
  unscaled time.
- **Don't add text.** Subtitles, the speech bubble and the card carry the AI's reading. Add no new `Subtitles.Show*`
  lines and no HUD widgets (the HUD was just trimmed on purpose).
- **No camera shake or big zooms.** Judges watch the projected screen and the drawing; `Player/CameraFollow.cs`
  already does the Reveal zoom. A gentle punch of at most ~0.1 m is the limit, and only for the win.
- **Keep it cheap and offline.** Use no new packages; ship audio as small files under `Assets/Audio/` (CC0). Effects
  must survive F5 (`RunManager.RunReset`) with nothing left behind.

## Where to hook in
| Moment | Hook | What exists already |
|---|---|---|
| Drawing appears (the money shot) | `Core/RunManager.cs` `SpawnInvention` (~L652); `Multiplayer/ExplorerInventions.cs` `Spawned` event | `Sockets/Cutout.cs` ~L108 damped spawn wobble. Add a paper "thwip" sound and an ink-dust puff here |
| "Hmm, what is it..." wait | `RunManager.cs` ~L374 | Nothing. A soft pencil-scribble loop that stops when the card shows is a good fit |
| Card shows (accepted/refused) | `UI/InventionCard.cs` `Show` (~L83), `worked` true/false | A paper note. Add a chime vs. a thud, using unscaled-time audio |
| Gatekeeper refuses / eats | `Sockets/VillagerSocket.cs` `OnSolved` (~L56), confetti on cut-up | Add a munch and a scissor snip |
| Gap bridged | `Sockets/GapSocket.cs` `OnSolved` (~L88) | Add a plank "clack" when the bridge lands |
| Any puzzle solved | `Sockets/PuzzleSocket.cs` `Solve()` (~L132) | A shared small "ding" here covers all sockets |
| Jump / land | `Player/PlayerController.cs` (jump callback ~L81, `IsGrounded` ~L115) | Squash and confetti exist. Add footstep/land paper taps |
| Stomp a creature | `Inventions/InventionMotion.cs` `TrySquash` (~L57) | Paper confetti exists. Add a crumple sound |
| Ride / thrust / out of fuel | `Inventions/InventionPhysics.cs` `TryInteract` (~L102), fuel-out ~L194; `Inventions/LaunchPad.cs` | The thrust ParticleSystem is in `InventionMotion.cs`. Add a whoosh and a sputter |
| Checkpoint | `RunManager.cs` ~L973 | Add a small chime only |
| Win | `RunManager.Won` event (L121), `UI/Hud.cs` finished screen (~L67) | Add a confetti burst at the flag and a short fanfare |

The easiest structure: one `Juice` MonoBehaviour (with static `Play(clip, position)` and `Puff(position)`) that
subscribes to the existing events and gets one-line calls at the hooks above, so gameplay code barely changes.

## Don't touch
- The `/interpret` backend, `tools/thinkink_system_prompt.txt`, `server/` (SpacetimeDB is a teammate's), and the
  placement/ghost logic in `Inventions/InventionPlacement.cs` and `BuildGhost.cs`.
- `Assets/Scenes/Level.unity` is generated by `Game > Rebuild Level Greybox` (`Assets/Editor/SceneBuilder.cs`). Add
  the `Juice` object in `SceneBuilder` rather than by hand, and diff the scene for hand-added prefabs (Coop) before
  rebuilding.
